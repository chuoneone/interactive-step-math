# 數學互動網頁生成 Skill

## 目標

將使用者提供的數學題目（一題或多題），生成完整可直接在瀏覽器執行的「選項點擊填入式」互動解題 HTML 網頁。

---

## 執行流程

### Step 1：題型判定

先用**一句話**標記題目類型，例如：
- 比例、速度、一次方程式、圖表判讀、幾何、分數加減、面積、單位換算……

此判定決定後續所有步驟的設計方向，不可偏離。

### Step 2：題目守門（必查清單）

在產出前逐項確認：

- [ ] 只使用題目中出現的數字、單位、符號與概念，**不自行新增**
- [ ] 不將題目改寫成其他題型
- [ ] **只有**題目文字明確出現分數時，才使用 `.fraction` / `.mixed` 的 HTML class；否則完全不出現這些 class
- [ ] 若有圖形需求，用 `<svg>` 建置，不使用 `<img>`

### Step 3：產出完整 HTML 網頁

依照以下規格一次產出完整可執行的單一 HTML 檔案。
- **必須確保** `<head>` 區塊內加入使用者的專屬 icon：`<link rel="icon" href="../images/dog.png" type="image/png">`。

### Step 4：整合至單元首頁 (如果是新單元或新頁面)

如果使用者是「新增」不同的題型或是新增單元，必須主動進行以下兩個動作：
1. **建立新的 HTML 檔案**：
   - 將產出的完整互動 HTML 程式碼直接存入 `math/` 資料夾下，並依照既有規則命名（如 `G8S2-X-X-XX.html` 或自定義有意義的名稱）。
2. **更新索引 (Index) 頁面**：
   - 到對應的年級/單元主頁（例如 `8.html` 或 `index.html`），適當地新增一顆導覽按鈕。
   - 按鈕樣式應比照該首頁既有的風格。
   - 將按鈕超連結 (`href`) 指向剛剛新產出的 HTML 檔案。

## 互動設計規格

### 🧩 填答機制

1. **步驟拆解（Step-by-step）**
   - 依概念拆成 Step 1 → Step 2 → Step 3……
   - 每步驟只做一件事：一句短指令 + slot（填答格）+ 選項按鈕

2. **點擊填入**
   - 點擊選項按鈕 → 自動填入「最前方未填」的 slot
   - 已用選項自動禁用
   - 點擊 slot → 清除答案並重新啟用對應選項

3. **順序控制**
   - 必須依序填入，不能跳格
   - 有空格未填就按「檢查答案」→ 顯示「請填滿所有空格」

4. **檢查答案**
   - ✔ 正確 → 綠色提示 + Tada 動畫或 SVG 勾勾
   - ✖ 錯誤 → 顯示「再想想看」，**不清除**學生已填內容

5. **步驟解鎖**
   - 同一題必須逐步解鎖，不一次全展開
   - 當前步驟答對 → 自動解鎖下一步，畫面平滑捲動
   - 已完成步驟保持可見，但**隱藏已完成步驟的選項按鈕**

6. **視覺完成提示**
   - slot 邊框改為藍/綠色表示完成
   - 步驟標題旁顯示「✔ 完成」
   - 全部完成後彈出完成視窗，含兩個按鈕：
     - 「再做一次」→ 清空答題內容
     - 「關閉視窗」→ 關閉視窗並保留答題結果

7. **題目重點標示**
   - 使用 `<mark>` 強調題目中的重要資訊（關鍵數字、單位、條件）

8. **計時與排行榜系統**
   - 新增 7 分鐘（420 秒）倒數計時挑戰模式，並在導覽列右上角顯示剩餘時間與「排行榜」按鈕。
   - 一進入網頁需跳出「開始視窗」要求填寫玩家名稱，點擊開始後才計時。
   - 分數計算公式：`完成題數 * 1000 + 剩餘秒數`。
   - 所有題目完成或時間歸零時，顯示結算視窗與得分，並將成績紀錄於本機端 `localStorage`（各個單元必須有獨立的 key，如 `math_leaderboard_XXX`）。
   - 包含排行榜功能，可顯示前十名本地紀錄，包含姓名、花費時間、完成題數與結算分數。

## 排版規格

### 桌機/平板（md 以上，橫式）

```
┌─────────────────┬──────────────────────────────┐
│  題目（左側）     │  步驟解鎖流程（右側）          │
│  sticky top-0   │  垂直由上而下                  │
│  md:w-1/3       │  每步驟簡短：指令+slot+按鈕     │
└─────────────────┴──────────────────────────────┘
```

### 手機（md 以下，直式）

```
題目（上）
  ↓
步驟（依序解鎖，緊湊可捲動）
```

---

## 多題導覽列（有多題時必加）

- 最上方加可左右滑動的導覽列
- 最左邊顯示單元名稱
- 每題一個按鈕（題目 1、題目 2……）
- 點擊切換題目，**保留各題答題進度**
- 手機可橫向滑動（`overflow-x-auto`）

## 數學式 HTML 規格

遇到以下數學元素時，使用 HTML + CSS 呈現，**不得使用 LaTeX 或斜線**：

```css
.math {
  font-size: 28px;
  font-weight: 600;
  display: inline-flex;
  align-items: center;
  gap: 4px;
}
.fraction {
  display: inline-flex;
  flex-direction: column;
  align-items: center;
  line-height: 1.1;
}
.fraction span:first-child {
  border-bottom: 2px solid #000;
  padding: 0 4px;
}
.power {
  font-size: 18px;
  vertical-align: super;
  margin-left: 2px;
  color: #e63946;
}
.sqrt::before { content: "√"; font-size: 28px; margin-right: 2px; }
.abs::before { content: "|"; }
.abs::after { content: "|"; }
.mixed { display: inline-flex; align-items: center; gap: 2px; }
```

> ⚠️ 只有題目中明確出現分數時才使用 `.fraction` / `.mixed`

## 技術規格

- **技術棧**：HTML + Tailwind CSS（CDN）+ 原生 JavaScript
- **禁止**：Vue、React 或任何前端框架
- **字型**：偏大（方便特教生閱讀）
- **按鈕間距**：清楚寬鬆
- **響應式**：滿版 + 滑動過渡效果

---

## 輸出要求

產出**一個完整 HTML 檔案**，若有需要建置新單元，請直接使用工具存入對應的 `math/` 資料夾中並更新首頁連結；否則請提供完整的程式碼，確保包含：

1. **完整 HTML 結構**（題目區 + 步驟區 + 多題導覽列）
2. **完整 CSS**（Tailwind CDN + 追加自訂樣式）
3. **完整 JavaScript**：
   - 點擊填入 / 清除 slot
   - 禁用/恢復選項按鈕
   - 檢查答案邏輯
   - 步驟解鎖與捲動
   - 多題切換（含進度保留）
   - 計時器倒數邏輯與開始畫面
   - 成績計算與 LocalStorage 排行榜存取邏輯
   - 響應式排版控制

> ⚠️ 程式碼不可殘缺，必須完整可執行
