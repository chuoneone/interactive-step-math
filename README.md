# 💻 互動式數學 (Interactive Math) Skill

> **簡介與說明**：專為特教老師、數學教材設計師與學生打造的互動式數學解題工具生成器。提供「選項點擊填入式」與「鍵盤輸入式」雙模式，自動產出具備逐步解鎖 (Step-by-step unlock)、高品質 KaTeX 公式渲染、Tailwind 響應式佈局、答錯防呆訂正與 Web Audio 音效提示的單一 HTML 互動教學網頁。

---

## 🌟 核心特色

1. **雙互動模式支援**：
   - 💻 **選項點擊填入版 (Click-to-Fill)**：自動提供打亂順序的選項按鈕，點擊自動依序填入 Slot 格，適合觸控或點擊操作。
   - ⌨️ **鍵盤自行輸入版 (Input-Text)**：特教友善大字體 Input 框，支援鍵盤輸入、Enter 自動跳格與數值檢驗。
2. **前置詢問與題數自訂機制**：
   - 模式未指定時主動詢問模式（點擊版 vs 輸入版）。
   - 支援選擇題數（1 題目前題目 / 3 題 / 5 題同概念練習題），多題自動配置頂部橫向滑動導覽列與倒數計時器。
3. **題型守門與嚴謹性**：
   - 嚴格鎖定原題數字、單位與概念，禁止自行改寫題型或硬套分數。
   - 支援原生 `<svg>` 繪製幾何圖形、數線與圖表。
4. **精準數學式渲染**：
   - 全面採用 KaTeX 渲染固定公式，杜絕斜線分數（`1/2`）與圖片式算式。
   - 「KaTeX 固定算式 + HTML Slot/Input」混合排版，對齊工整美觀。
5. **鷹架式逐步解鎖 (Step-by-step Unlock)**：
   - 每步驟專注單一運算或觀念，答對播放清脆提示音並平滑捲動解鎖下一步。
   - 答錯提示「再想想看喔」，保留已填內容進行訂正，不重複計分。
   - 完成所有步驟後彈出結算視窗（支援「再做一次」與「關閉視窗」）。


---

## 🚀 如何安裝與使用 Skill

將 `SKILL.md` 放置於 Antigravity 的 Skills 目錄中：
```text
~/.gemini/config/skills/interactive-math/SKILL.md
```

在對話中貼上數學題目或截圖，並提及「做成互動數學網頁」、「點擊版數學」或「輸入版數學」，Agent 即會啟動前置詢問並產出完整可直接執行的 HTML 檔案。
