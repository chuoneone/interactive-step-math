三、合併同類項

🐻
訣竅 尋找有相同文字符號（例如 x 跟 x，y 跟 y）的項，連同前面的正負號一起抓出來合併喔！
1
x + 3y + 3x + 4y
合併步驟： ( + ) + ( + )
答案：　　 = +
詳解：
(x + 3x) + (3y + 4y) = 4x + 7y
2
2x - y + 3x + 4y
合併步驟： ( + ) + ( + )
答案：　　 = +
詳解：
(2x + 3x) + (-y + 4y) = 5x + 3y
3
x - 2y - 5x + y
合併步驟： ( + ) + ( + )
答案：　　 = -
詳解：
(x - 5x) + (-2y + y) = -4x - y
4
4x - 6y - 2x + 4y
詳解：(答案是 A)
(4x - 2x) + (-6y + 4y) = 2x - 2y
5
-x + 2y - 3x - 5y
詳解：(答案是 A)
(-x - 3x) + (2y - 5y) = -4x - 3y
